# דייטים

אפליקציה אישית לרעיונות לדייטים — ולהפיכת כל רעיון לאתר HTTPS שאפשר לשלוח לבת הזוג.

נבנתה ב-React + Vite + TypeScript + Tailwind, באותו סגנון של [training](https://github.com/arbel2103/training).
הנתונים נשמרים מקומית בדפדפן (`localStorage`).

## שני עולמות באפליקציה אחת

| | |
|---|---|
| **הסטודיו** (`/`) | מה שאתה רואה: מאגר הרעיונות, בניית הגלגל, בניית המסע, והקישורים שפרסמת. |
| **אתר־המתנה** (`/#/v/…`, `/#/g/…`) | מה שהיא רואה. שש סצנות: פתק פתיחה, מכתב שנכתב אות־אות, פאזל, גלריית תמונות, גלגל, והזמנה. |

מתנה היא פשוט רשימה מסודרת של סצנות — "אתר גלגל" הוא מתנה עם סצנה אחת, ו"מסע" הוא רצף.

## הרצה מקומית

```bash
npm install
npm run dev      # נפתח ב-http://localhost:5173/dates/
npm test         # בדיקות יחידה
npm run lint
```

## איך "הפוך לאתר" עובד

יש שני מסלולים, והאפליקציה בוחרת ביניהם לבד:

**מתנה בלי תמונות** (גלגל, מכתב, הזמנה) נדחסת ונכנסת כולה לתוך הקישור עצמו:
`…/dates/#/v/<תוכן>`. גלגל טיפוסי יוצא כ־450 תווים. אין שום קובץ בשרת, אין מה שיפוג,
ולא צריך שום הגדרה.

**מתנה עם תמונות** גדולה מדי בשביל קישור, ולכן:

1. התוכן נדחס ומוצפן ב-AES-GCM 256 בדפדפן שלך.
2. הצופן נדחף כקובץ לענף `gifts` בריפו הזה (Git Data API, commit אחד).
   הענף הזה לא מפעיל את ה-build של Pages, ולכן הפרסום לוקח שניות ולא דקה.
3. הקישור הוא `…/dates/#/g/<owner>/<repo>/<id>/<מפתח>`. **כל מה שאחרי ה-`#` לא נשלח
   לשום שרת** — GitHub מחזיק בייטים שהוא לא יכול לקרוא, והמפתח קיים רק בקישור עצמו.
4. הדפדפן שלה מושך את הקובץ מ-`raw.githubusercontent.com` ומפענח אצלה.

מי שאין לו את הקישור המלא לא יכול לפתוח את המתנה, גם אם ימצא את הקובץ בריפו.

### הגדרה חד־פעמית (רק למתנות עם תמונות)

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `arbel2103/dates`.
3. Permissions → Repository permissions → **Contents: Read and write**.
4. להדביק את הטוקן בעמוד **הגדרות** באפליקציה וללחוץ "שמור ובדוק חיבור".

הטוקן נשמר רק בדפדפן שלך ולא נכנס לשום דבר שמתפרסם. הענף `gifts` נוצר לבד בפרסום הראשון.

## פריסה ל-GitHub Pages

1. Settings → **Pages** → Source = **GitHub Actions**.
2. כל push ל-`main` מפרסם אוטומטית דרך `.github/workflows/deploy.yml`.
3. האתר יהיה ב-`https://arbel2103.github.io/dates/`.

> אם שם הריפו משתנה, צריך לעדכן את `base` ב-`vite.config.ts`, את הנתיבים ב-`public/manifest.webmanifest`
> ואת `SHELL` ב-`public/sw.js`.

## התקנה למסך הבית

האתר הוא PWA. באייפון: Safari → שיתוף → "הוסף למסך הבית". באנדרואיד/מחשב: Chrome → "התקן אפליקציה".
הלוגו (`public/logo.svg`) והאייקונים נוצרים ממנו.

## מבנה

```
src/
├── lib/          המנוע: קידוד והצפנה של מתנות, לקוח GitHub, גאומטריה של הגלגל והפאזל
├── store/        zustand + persist — רעיונות, מתנות, הגדרות
├── seed/         49 רעיונות שהאפליקציה מגיעה איתם
├── gift/         אתר־המתנה: עורות רקע, שש הסצנות, אפקטים, ו-gift.css
└── studio/       הסטודיו: חמישה עמודים ורכיבי UI משותפים
```

העיצוב של אתר־המתנה יושב כולו ב-`src/gift/gift.css` — צבעים, ניירות, ואנימציות במקום אחד,
כדי שאפשר יהיה להשוות אותו לסרטוני הייחוס במקום שיזלוג לאט.

## בדיקות

`npm test` מריץ את בדיקות היחידה (קידוד והצפנה, זוויות הגלגל, גאומטריית הפאזל, ה-stores).

`scripts/verify-gift.mjs` בודק בדפדפן אמיתי את מה שבדיקות יחידה לא מגיעות אליו — גרירת חלקי
פאזל עד שהם ננעלים, כפתור ה"לא" שבורח, ומתנה שעוברת את כל הדרך מהסטודיו לקישור שנפתח בדפדפן
נקי, כולל המסלול המוצפן:

```bash
npm run dev            # בטרמינל אחד
npm i -D playwright    # פעם אחת; לא תלות קבועה, כדי שהפריסה לא תוריד דפדפן
node scripts/verify-gift.mjs
```
